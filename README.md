## How to Run

1. Clone the repository:
   `git clone https://github.com/zxllllll-cmd/CISC7204-mc64181-2026GitHub.git`
2. Open any Module folder and launch the `.ipynb` notebook in Jupyter.
3. Required packages: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`.

Datasets are included as `.csv` files alongside each notebook.
